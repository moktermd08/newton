# newton

## Lab

`/admin/lab` is an all-JSON workspace for the software lifecycle: Functions, Patterns, Journeys, Templates,
Configuration, Feedback & Learning, Agents, Data and Schema. Each area is one file in `lab/` (override the
folder with `LAB_DIR`); commit them so git records how a pattern improved. The Schema area defines every
area's fields, so change the schema and the forms follow. `/api/lab/export` downloads everything as one JSON
document for moving proven patterns to the live platform.
